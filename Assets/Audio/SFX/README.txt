EFECTOS DE SONIDO DEL JUEGO
===========================

Coloca en esta carpeta los efectos de sonido reales del juego.

El sistema acepta dos formatos para cada efecto:
- .wav (preferido para efectos cortos)
- .mp3 (alternativa)

Si existen los dos archivos con el mismo nombre, se cargara primero el .wav.

NOMBRES ESPERADOS
-----------------

ui_mover.wav / ui_mover.mp3
    Sonido al mover la seleccion en menus.

ui_confirmar.wav / ui_confirmar.mp3
    Sonido al confirmar una opcion.

cuenta_regresiva.wav / cuenta_regresiva.mp3
    Sonido para 3, 2, 1 antes de un minijuego.

inicio_minijuego.wav / inicio_minijuego.mp3
    Sonido al comenzar la ronda.

recoger_nucleo.wav / recoger_nucleo.mp3
    Sonido al recoger un nucleo normal.

recoger_nucleo_especial.wav / recoger_nucleo_especial.mp3
    Sonido al recoger un nucleo especial/dorado.

alerta_tiempo.wav / alerta_tiempo.mp3
    Aviso durante los ultimos segundos.

resultado.wav / resultado.mp3
    Sonido al mostrar el resultado del minijuego.

No es obligatorio tener todos los archivos. Si falta alguno, el juego continua funcionando y muestra un aviso en la consola.
